# Netflix Power BI Dashboard 🎬📊
Interactive Power BI dashboard analysis of Netflix Movies and TV Shows

## 📌 Project Overview
This project presents an interactive Power BI dashboard built using Netflix Movies and TV Shows data.  
The dashboard provides insights into content growth, type distribution, ratings, duration patterns, and top contributing countries.

The goal of this project is to analyze Netflix’s content library and present key insights through clean and interactive visualizations.

---

## 🎯 Objectives
- Analyze the total number of titles available on Netflix
- Compare Movies vs TV Shows distribution
- Observe how content has grown over the years
- Analyze movie duration patterns
- Understand rating-wise content distribution
- Identify top countries contributing Netflix content

## 📈 Key Insights
- Netflix hosts **8800+ titles**, with Movies contributing around **70%**
- Rapid growth in content additions after **2015**
- Majority of movies fall under **less than 120 minutes**
- **TV-MA** and **TV-14** are the most common ratings
- **United States and India** are top content-producing countries
